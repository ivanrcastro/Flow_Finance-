# 🌊 Flow Finance
**A minimal, professional, and private personal finance manager.**

**Flow Finance** is a React-based web application designed to give you a seamless overview of your monthly spending without the clutter of traditional banking apps.

---

## ✨ Features

* **User-Centric Dashboard**: Personalized greeting with auto-extracted display names.
* **Monthly Budgeting**: Set your limit and track your progress in real-time.
* **MTD Comparison**: Compare your current spending with the previous month (Month-to-Date).
* **Smart Categorization**: Visualize your spending habits with an interactive Pie Chart.
* **Privacy First**: Built on Supabase with secure authentication and private data storage.
* **Responsive Design**: Fully optimized for a mobile-first experience.

---

## 🛠️ Tech Stack

* **Frontend**: React.js & Tailwind CSS
* **Animations**: Framer Motion
* **Charts**: Recharts
* **Backend/Database**: Supabase (PostgreSQL)
* **Authentication**: Supabase Auth

---

## 🚀 Getting Started
